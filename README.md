# bitwig-mods-list

Bitwig Studio mods for Patchbay (BML). By Marius R. An unofficial project, not affiliated with Bitwig GmbH.

## Install

The easiest way is [Patchbay Launcher](https://github.com/arius77R/patchbay-launcher): Sources → Source list → arius77R/bitwig-mods-list → "Add to active", then the Mods tab.

Without the launcher: download the ZIP from [Releases](https://github.com/arius77R/bitwig-mods-list/releases) and add it in Patchbay through Mods → Add Mod…

## How the repository is laid out

Each mod has a folder `<mod-id>/` with its `mod.json`, and its package `<mod-id>-<version>.zip` in Releases.
The repository follows the [Patchbay Launcher publishing rules](https://github.com/arius77R/patchbay-launcher/blob/main/docs/PUBLISHING.md).
